# Stage 2: minimal honest core, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a reproducible, validation-only run that shows emissions-first stay, wait or travel decisions for Seren jobs arriving in Utah. It compares forecasts and policies, with honest work accounting, and exports results that the offline dashboard renders. The checkable build is due Tue 18:00 MT.

**Architecture:**
- **Data:** carbon truth (EIA workbooks) and grid series feed forecasters, which respect publication envelopes. The Seren replay produces jobs.
- **Simulation:** an event-driven gang-job simulator with exact-interval capacity runs the policies U/G/S/K/W/L/H and writes a ledger.
- **Evaluation:** accounting, a relaxed lower bound and a block bootstrap produce `results/*.json` with evidence envelopes.
- **Display:** a Vite app renders those results offline.

**Tech stack:**
- Python 3.12 / uv / polars / numpy / scikit-learn (HistGradientBoostingRegressor) / fastexcel (dev group);
- Vite + React + TypeScript, ECharts, deck.gl + MapLibre.

**Spec:** `docs/superpowers/specs/2026-10-27-gridpilot-design.md`. **§15 F1–F14 override earlier sections.** Executors read the spec sections each task cites.

## Global Constraints

- **Seal.** No values at or after `TEST_START` (2025-11-01T00:00Z) are read anywhere in this plan. Every loader defaults to `gridpilot.splits.drop_sealed` (F8).
- **Validation window** (F2):
  - selection cohort arrivals are [2024-11-01T00:00Z, A_val), with A_val = 2025-10-24T00:00Z − 336 h − W_max;
  - warm-up is ≥ 15 days under U;
  - truth requests at or after TEST_START raise.
- **Core sites and capacity** (§7 table, F5): PACE 2,288 slots (home); CISO, BPAT and NEVP 512 spare slots each.
- **Transfer:** 30 min before execution. Energy is 5% of the job's IT energy, booked at arrival, half at source and half at destination, with PUE applied at each end (F7).
- **Power:**
  - 0.60 kW active per allocated GPU slot;
  - PUE 1.20 at each site;
  - idle power is sensitivity-only (F7).
- **Flexibility:**
  - candidate job types are Pretrain, SFT, MLLM and Eval;
  - a job is flexible iff `int(sha256(f"{source_job_id}:42").hexdigest(), 16) % 2 == 0`;
  - allowed delay: Pretrain/SFT/MLLM 6 h, Eval 1 h, everything else 0 h;
  - mobility: flexible jobs may run at any core site with enough slots.
- **Deadlines** (F1): `deadline = max(arrival + duration + allowed_delay, finish_under_U)`.
- **Carbon:** the primary signal is EIA consumption-based hourly intensity in g/kWh, stored with production-based intensity alongside. Workbook intensities are lb/kWh; g/kWh = lb/kWh × 453.592.
- **Forecasts:**
  - issued daily at 10:00 America/Denver, for the next Utah civil day;
  - availability envelopes: demand +2 h; wind and solar +48 h; consumed intensity +96 h;
  - the BA's DF is never a feature.
- **Labels:** every exported number carries an evidence class: observed, measured, forecast, modeled, assumed or simulated.
- **Commits:** end with the Co-Authored-By and Claude-Session lines. Run `cd lab && uv run pytest` before every commit.

## Review Focus

1. **A gang job whose hourly-average occupancy fits but whose exact overlap exceeds capacity** must be rejected (Task 4).
2. **A truth hour missing at a destination** closes that destination for any start touching it. That applies to every policy, to H and to the bound alike (Tasks 5 and 6).
3. **A job crossing midnight, a DST change or the edge of forecast coverage** is integrated over its full duration, and its tail uses climatology (Task 5).
4. **A negative saving** stays negative from the ledger through to `metrics.json` (Task 6).
5. **A replay instance at a cycle seam** keeps unique IDs and its flexibility flag (Task 3).

### Task 4: Exact-interval capacity, the ledger, and policies U/G/S

**Files:**
- Create: `lab/src/gridpilot/sim/__init__.py`, `lab/src/gridpilot/sim/capacity.py`, `lab/src/gridpilot/sim/engine.py`
- Test: `lab/tests/test_sim_core.py`

**Interfaces:**
- **Consumes:** the `replay()` frame (Task 3).
- **Produces:**
  - `class Capacity(slots: int)`, with:
    - `max_in(start: float, end: float) -> int` (exact interval maximum);
    - `fits(start, end, gpus) -> bool`;
    - `reserve(start, end, gpus) -> None`;
    - an interval or segment structure, not hourly bins (F10).
  - `SITES = {"PACE": 2288, "CISO": 512, "BPAT": 512, "NEVP": 512}`.
  - `simulate(jobs: pl.DataFrame, policy: Policy, *, sites=SITES, deadlines: pl.DataFrame | None, warmup_state=None) -> Ledger`.
    - `Ledger` is a `pl.DataFrame` with columns `job_uid, site, start_ts, end_ts, transfer, late, deadline_ts, gpus`.
  - `Policy` protocol: `choose(job, now, capacities, ctx) -> Action(site, start)`.
  - Implementations:
    - `U`: earliest feasible at PACE, FIFO; simultaneous arrivals ordered by deadline, then `job_uid`.
    - `G`: earliest finish across sites, then home, then BA code.
    - `S`: rank sites by the training-window unweighted mean of consumed intensity, then the earliest feasible completion at each ranked site.
  - Remote starts include the 30 min transfer. Infeasible jobs go to the late queue: scheduled at the earliest legal start, `late=True`, never dropped.
  - `u_finish_deadlines(jobs) -> pl.DataFrame` with columns `job_uid, deadline_ts`. It implements the F1 rule using a U run.

### Task 5: Carbon search K/W/L/H, transfer energy, and the site mask

**Files:**
- Create: `lab/src/gridpilot/sim/carbon_search.py`
- Test: `lab/tests/test_carbon_search.py`

**Interfaces:**
- **Consumes:**
  - `Capacity`, `simulate`, `Policy`, `Action` (Task 4);
  - the forecast frame (Task 2);
  - `site_mask` and `load_carbon` (Task 1).
- **Produces:**
  - `CarbonSearch(signal: Literal["K","W","L","H"], forecasts, truth, mask)`, which implements `Policy`.
  - Candidate starts are hourly boundaries plus the earliest feasible start at each site, within `[arrival, arrival + max_delay]` (F10).
  - Predicted CO₂ is the exact-overlap integral of hourly intensity over the full job, plus attributed transfer energy.
  - Beyond issued coverage, a climatology tail is used; H uses realized truth.
  - Ties within 1e-9 kg go to: earlier completion, then PACE, then BA code, then start.
  - A start touching a destination's masked hour is illegal (F3).
  - `job_energy_kwh(gpus, duration_s) = gpus * 0.60 * duration_s / 3600 * 1.20`.
  - `transfer_kwh = 0.05 * gpus * 0.60 * duration_s / 3600`, with PUE applied at each half.

- [ ] **Step 1: Write the failing tests**
  - `test_integral_partial_hours`: a 90-minute job starting at :30 integrates 0.5 / 1.0 h weights exactly.
  - `test_tail_uses_climatology`: a job ending beyond the last issued target uses K values for the tail.
  - `test_mask_closes_destination`: a masked BPAT hour inside the window makes BPAT illegal.
  - `test_inflexible_stays`: a non-flexible job is placed at PACE at arrival.
  - `test_H_uses_truth`: H's choice equals the argmin over realized intensity.
- [ ] **Step 2:** Run the tests and expect FAIL.
